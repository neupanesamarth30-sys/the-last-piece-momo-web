# THE LAST PIECE MOMO — Web build

This repository contains the browser export. The public itch.io page is the easiest way to play:

https://idioticgng.itch.io/the-last-piece-momo

To keep a local copy, download and extract `the-last-piece-momo-web.zip`. The archive contains the Godot HTML, JavaScript, WebAssembly, and game data files used by itch.io.
